NoteKeeper

Collaborative note-taking system - Phase-1 JSF prototype

Phase-1 Practical Project

JSF + Hibernate CRUD Demonstration

This prototype implements full Create, Read, Update, and Delete operations for two NoteKeeper entities: Tag and Workspace. It uses Hibernate for persistence and three validation types plus three CSS types.

1. Tag Management

Create colored labels used to organize notes. Validation covers name uniqueness, length, and hex color format.

2. Workspace Management

Create workspaces that group notes for personal or team use. Validation covers reserved names, length, and required owner.

Assignment checklist demonstrated here

  • JSF pages with backing beans
  • Hibernate mapping and CRUD through DAOs
  • Bean Validation, JSF built-in validators, and custom validators
  • External CSS (app.css), internal CSS (this page), and inline CSS (page titles)
